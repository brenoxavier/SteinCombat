# Combat 0.1.21: pela API pública

O Combat agora liga os ajustes de corrida e de golpe pela API pública do Stein Loader, como qualquer outro mod, em vez de uma parte do Loader reservada para ele.

- **Precisa do Stein Loader 0.1.25**: o Stein Client e o instalador atualizam o Loader sozinhos. Nada muda no funcionamento do Combat, e suas configurações continuam onde estão.
