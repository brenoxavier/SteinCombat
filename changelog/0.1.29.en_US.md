# Combat 0.1.29: the target moved here, and servers can turn features off

The target element leaves the HUD and becomes part of Combat, which is an official Stein Project mod again, as an extra.

- **Target**: the head, name, distance, health, armor and held item of whoever you are fighting, in the same place on the screen and with the same options as before.
- **Servers**: a server can turn off the whole mod or its features: target, No Hit Delay, Autoclick, sprint, Auto Walk, Auto Armor, Auto Refill and Smart Effect.
- **New address**: the mod now lives at `Stein-Project/combat`. Whoever already uses it keeps getting updates.
- **Update notice**: the Loader's Panel shows when a new version of this mod is out.
