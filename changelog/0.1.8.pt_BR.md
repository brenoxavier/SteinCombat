# Esconder aliados respeita a opção "Meu clã é aliado"

Com essa opção desligada, o seu clã não é aliado para nada — não é protegido do seu golpe, não tem a cor de aliado — mas mesmo assim sumia quando você apertava a tecla de esconder. Agora não some mais.

- **Some exatamente quem a proteção de golpe protege**: os nicks marcados, os clãs aliados e, só com "Meu clã é aliado" ligada, o seu próprio clã.
- **Com a opção desligada**, o seu clã continua na tela junto com todo mundo; os clãs aliados e os nicks marcados continuam sumindo.
