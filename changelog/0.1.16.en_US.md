# Combat 0.1.16: Auto Armor, Smart Effect, Auto Protect and Auto Refill

Requires Stein Loader 0.1.26.

- **New names**, always in English: No Hit Delay, Keep Sprint, Omni Sprint, Toggle Sprint, Clan Protect and Hidden Allies. Only the names changed.
- **Keys in the Panel**: each feature has its key on its own row (the same as in Controls).
- **Active features**: a new HUD element listing what is on.
- **Auto Armor**: replaces when broken or swaps before, per piece or for all, choosing by protection (highest or lowest first). It can skip unenchanted pieces, prefer the most or least durable, and never break Protection IV to X pieces. Works with any screen open, without opening the inventory.
- **Auto Refill**: fetches armor from the server's virtual chest (`/bau vip`), when it runs out or keeping a number of spares, without showing the chest. It can store worn pieces back.
- **Smart Effect**: keeps Regeneration (enchanted apple), Speed and Strength, always, with an enemy nearby or when taking damage. If the server does not confirm a use, it tries again right away.
- **Auto Protect**: with a screen open, blocks with the sword.
- **Order**: armor, Regeneration, blocking, Speed and Strength. Then back to the last weapon.
